# FidgetHarp-Web

An HTML5 version of the Fidget Harp autoharp. This virtual instrument provides a relaxing and accessible musical experience optimized for web browsers.

## Features
* **Virtual Autoharp:** Intuitive interface for strumming and playing chords.
* **HTML5 Audio:** Responsive sound generation directly in the browser.
* **Cross-Platform:** Designed to work smoothly on both desktop and mobile web browsers.
